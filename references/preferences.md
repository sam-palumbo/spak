- Proposing to delete or merge a file: first say what only that file holds.
- Checks while working: only the ones named for what changed; the full suite
  once, at the end, before review.
- Renders while working: only the spots a change touches; one full set for
  the review.
- Timing: one alternated frame-time pair at the end.
- Self-check evidence: the check output and a line per render; no
  measurement made only for the self-check unless a point is in doubt.
